Privacy Policy

New Logic Software, LLC · Effective October 5, 2026

Scope

This policy covers New Logic Backup, an internal tool New Logic Software uses to back up its own business records to its own Google Drive using rclone and Google's Drive API.

Who uses it

The tool is used only by New Logic Software's owner, signed in to New Logic's own Google account. It is not offered to, and does not access the accounts of, any other person or organization.

Google user data

  • Access: the tool uses Google Drive API access to upload, list, and download New Logic's backup files in New Logic's Drive.
  • Use: solely to create, verify, and restore New Logic's own backups.
  • Sharing: no Google user data is sold, shared with, or transferred to any third party.
  • Storage: backup files are encrypted on New Logic's computer before upload. OAuth tokens are stored only on New Logic's computer and are not transmitted anywhere except to Google.
  • Collection: no personal data is collected from anyone, and no analytics or tracking are used.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

New Logic Backup's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
